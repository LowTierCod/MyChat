1. Про Циклы и Итераторы 🏃‍♂️

    Итератор — это «одноразовый бегунок». Когда ты пишешь for x in list:, Python ставит палец на первый элемент и двигается только вперед.
    Прошлого не существует. Как только итератор прошел элемент, он о нем забывает. Он не вернется назад сам по себе, даже если ты изменишь список.
    Не пили сук, на котором сидишь. Если удалять или добавлять элементы в список прямо во время for по нему же — итератор может «споткнуться» (пропустить элемент или выдать ошибку).

2. Про Память и Ссылки 🔗

    Python ленив. Когда ты пишешь a = b, ты не копируешь данные. Ты просто даешь одному и тому же объекту в памяти второе имя.
    Изменения общие. Если два имени (list1, list2) ведут к одной «корзине», то яблоко, положенное в одну, появится и во второй.
    Хочешь копию — проси явно. Используй .copy(), иначе будешь менять оригинал, сам того не желая.

3. Про Коварную Базу (Default Args) ⚠️

    def func(x=[]) — это ловушка! Список в аргументах создается ОДИН раз при запуске программы. Он станет «общей помойкой» для всех вызовов этой функции.
    Правило: Всегда пиши arg=None, а внутри функции проверяй if arg is None: arg = [].

4. Про WebSocket и Реальное время 🌐

    Каждый юзер — это отдельный мир. Когда подключается новый человек, твоя функция запускается для него с нуля.
    Общий список — это мост. Единственное, что связывает всех юзеров — это глобальная переменная (твой список active_connections).
    Цикл рассылки. Один цикл for при подключении отправит по одному сообщению всем, кто в списке сейчас. Он не будет магически повторяться для старых сообщений.
